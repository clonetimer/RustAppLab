# D8 · Edition 2024 实验室

这是独立现代教学路线，要求 Rust 1.100.0，标准库即可，无第三方依赖。经典主工作区、1.74 MSRV、C1/C2 保持不变。入口：[中文讲义](../../course/BOOK_D8_EDITION_2024.md)。

在本目录运行 `rustup show active-toolchain`，确认 1.100.0 已安装；首次安装需联网。源包中 `reference/` 是两个 Edition 的参考工作区；学员包只交付 `learner/` 与讲义，不含参考答案。

请先把 `learner/` **复制到自己的新目录**，保留原模板。编辑自己的 `src/lib.rs`，运行公开合同测试，留下输入、输出和解释。若想在完整源包复现实验，使用讲义中的参考命令和维护者脚本；参考程序通过不表示个人已经掌握。

本阶段独立 CLI 入口，不是网页工作台课程；不会自动导入旧学员工程或记录 LabQuest 成绩。
