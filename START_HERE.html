跟着做：Windows 路线

1

先确认电脑有 Rust

如果已经装过 Rust，可以直接做第 2 步。没有安装，请先打开 rustup.rs 官方网站，按照 Windows 安装说明完成；如提示 MSVC C++ Build Tools，请安装对应 C++ 桌面开发组件。安装完关闭原先的终端窗口。

检查方式：在 PowerShell 输入 cargo --version，能够看到版本号。
2

双击同目录的 START_WINDOWS.cmd

脚本会告诉你下一步，而不是把一堆命令扔给你。如果 Windows 弹出安全提示，请先确认文件确实来自你信任的 Rust AppLab 源码包。它不会替你安装 Rust，也不会删除学习文件。

预期：出现“第 0 关：30 分钟做出你的第一个 Rust 小软件”提示。
3

在记事本中只修改一行

向导自动创建 my-first-card/src/main.rs 并打开它。找到输出“等待完成第一张任务卡”的 println!，改成使用 name 与 task 的变量输出。保存时按 Ctrl+S。

目标示例：今日任务卡 | 小林 | 写 Rust
真的想不出来？点这里看逐级提示

提示 1：只关注 println!。提示 2：{name} 与 {task} 会被替换为真实输入。提示 3：在项目根目录运行 cargo run -p labquest -- beginner hint 3 才显示完整一行。

4

回到向导，按 Enter 进行检查

程序会真正编译你的 Rust，并用不同名字和任务运行。失败时看“期待 / 实际”的区别，再改、保存、重试。通过后会生成 my-first-card/FIRST_WIN.md。

预期：四项检查都通过，而不只是屏幕上出现“编译成功”。
5

保存自己的第一份作品

打开新生成工程中的 跟着做.md，按最后一节把运行结果保存到 我的任务卡.txt。这个文本才是你亲手开发的小工具生成的。

完成后：把任务从“写 Rust”换成“整理笔记”，再运行一次，确认内容随输入变化。

不用双击脚本也可以：手动命令

在 RustAppLab 根目录（就是有 Cargo.toml 的目录）打开 PowerShell，依次运行：

cargo run --offline -p labquest -- beginner start my-first-card
cargo run --offline --manifest-path my-first-card/Cargo.toml -- "小林" "写 Rust"
# 用记事本打开 my-first-card\src\main.rs，修改并保存一行
cargo run --offline -p labquest -- beginner check my-first-card
cargo run --offline -p labquest -- beginner hint 1
如果提示“目录已存在”，不要删除自己的文件。直接打开已有的 my-first-card 继续练习；需要新项目时更换目录名。

使用 Linux 的学员可以执行同样的 cargo run 命令，编辑器换为自己习惯的软件。Windows 原生兼容性仍需真实机器验收。

看不懂报错？先对照这里

PowerShell 找不到 cargo 或 rustc

Rust 工具链尚未安装，或者安装后还没有重新打开 PowerShell。到 rustup.rs 安装并重开终端，再输入 cargo --version。

出现 link.exe not found、MSVC 或 linker 错误

可能缺少 Windows C++ 构建工具。按 rustup 官方 Windows 安装说明配置 Visual Studio C++ Build Tools；无需重装 Rust AppLab 源码。

看到了 could not find Cargo.toml

PowerShell 可能进入了错误的目录。你可以从文件资源管理器进入 RustAppLab 文件夹，在地址栏输入 powershell 回车；用 dir Cargo.toml 检查当前目录确实有这个文件。

程序仍显示“等待完成第一张任务卡”

先在记事本按 Ctrl+S，确认打开的是 my-first-card/src/main.rs，不是 FileQuest 或其他项目源码。

程序编译失败；显示 expected、unclosed delimiter

多半是括号、双引号或分号少了一个。只修改指定的 println! 那一行，比较前后引号是否成对；然后运行 beginner hint 1 看提示。

编译成功了，但自动检查还是失败

编译通过只说明代码语法正确。检查器还会用其它名字运行，不能只写死“小林”的结果。要把 name 和 task 变量写进格式化字符串。

Windows 双击后闪退、打不开记事本

直接打开 PowerShell，通过上方“手动命令”运行，把出现的报错完整保留。无需删除项目或重新解压。用自己喜欢的编辑器打开 my-first-card/src/main.rs。
