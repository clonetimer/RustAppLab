# StoreDesk 分层提示

链接器错误先看完整包 course/SQLITE_SETUP.md；不要把环境故障当成 SQL 答案错误。

## 第 1 步
方向：SKU、name、stock 三种不同约束；函数只检查，不写库。
结构：SKU 使用 bytes 的 ASCII 判断，名称用 chars 数量和控制字符检查。
检查：正常分支返回 Ok(())；负库存不能靠强制类型转换“变正”。名称中的单引号应允许。

## 第 2 步
方向：先验证，再插入；重复 SKU 失败，不覆盖。
结构：`use sqlite::Param;`，SQL 固定为三列三个占位符，按序传两个 Text 和一个 Int。
检查：不要把 title/name 拼进 SQL。`?` 传播失败，最后返回 Ok(())。

## 第 3 步
方向：先校验整批输入，再进入一个 transaction 闭包。
结构：循环中用 UPDATE 的范围条件保障不超上下限，返回受影响行数不为 1 就 Err；随后插入同事务流水。
检查：第二项失败后第一项也要回滚。不要在循环里每次开一个独立事务，也不要在事务外写流水。
