# Rust AppLab 网页学习工作台

在同一网页阅读中文任务卡、修改学员工程、运行程序和进行正式检查。适用于 0.19.0-rc.4 源码包和对应平台的运行包。

## 启动工作台

1. 完整解压到可以写入的目录。Windows x64 双击 `START_WORKBENCH_WINDOWS.cmd`。Linux x86_64 在解压目录打开终端，执行 `./START_WORKBENCH.sh`。
2. 启动后保留终端窗口。若浏览器未自动打开，从窗口里的 `RUSTAPPLAB_WORKBENCH_URL=` 后复制完整的 `http://127.0.0.1:端口/` 地址，粘贴到浏览器地址栏。每次启动以当前窗口打印的地址为准。工作台只在本机访问。
3. 学完先保存。回到启动窗口按 Ctrl+C，停止本次工作台服务。

源码包首次打开时，脚本调用 Cargo 编译工作台。运行包自带编译好的 LabQuest，可直接打开页面。两个包都需要本机 Rust/Cargo 和系统构建工具，才能编译、运行或正式检查你的 Rust 源码。Windows 使用 MSVC 工具链及 Windows SDK，Linux 使用本机编译和链接工具。StoreDesk 还需要该课程原有的系统 SQLite 环境。具体要求见 [支持平台](../SUPPORTED_PLATFORMS.md) 和 [StoreDesk SQLite 环境说明](SQLITE_SETUP.md)。

脚本默认用脚本所在目录作为工作区。直接启动脚本且不传参数时，它会尝试打开浏览器。给脚本传入参数时，只有显式传入 `--open` 才会尝试打开浏览器。

## 从 FirstCard 开始

1. 在「学习路线」选择 **FirstCard · 第一张任务卡**。点击「创建学习项目」，工作台会在工作区下创建 `my-first-card`。如果标题下已经显示你的 FirstCard 工程路径，可以直接继续。
2. 先读「任务卡」里的目标、要改哪里和本步知识。写代码前预测换一组姓名和任务时，输出会怎样变化。卡住时按顺序展开「提示 1」「提示 2」「提示 3」，需要上下文时点「完整讲义」。
3. 在「源码编辑器」的「文件」中选择 `src/main.rs`。按任务卡修改 `println!` 那一行。点「保存」或按 Ctrl+S，看到「已保存」后，修改就写入标题下所示工程的文件。
4. 点击「正式检查」。初始 FirstCard 尚未实现任务要求，检查通常失败。展开「输出」查看真实结果。若有编译错误，先从第一条报错修起。每次检查前会保存当前编辑器中的修改。成功时输出显示当前步骤检查通过，再按任务卡做自己的输入实验。
5. 展开「运行参数」，每行写一个参数。一行内的空格会原样传给程序，无需引号，参数框留空会使用无参数运行。点击「运行程序」，比较实际输出。这里的一次运行成功只代表本次程序执行结束，课程通过由「正式检查」给出。

给 FirstCard 输入下面两行，第一行是姓名，第二行是任务。

```text
林 果
整理读书笔记
```

换一组姓名和任务再运行，然后按「想一想」解释这两次输出为何不同。准备好后，从「下一课 · UnitLab」进入单位换算练习。Studio 的正式检查会一并检查所选步骤和它之前的步骤。

## 打开旧工程与处理冲突

在「学习路线」选对应课程，把学员工程的实际目录粘贴到「已有项目目录」，再点「打开项目」。可直接输入含中文或空格的路径，例如 `D:\练习 Rust\我的 UnitLab`。打开会沿用目录中的源码。即使旧工程没有后来才加入的讲义文件，工作台仍会从课程数据提供任务卡和讲义。

如果另一个编辑器已经修改了同一个文件，保存时会提示冲突，草稿会留在网页编辑器里。需要两边的修改时，先复制草稿，再点「重读磁盘版本」并确认，接着把需要的内容合并回来。取消确认可以继续查看原草稿。切换到其他课程、替换当前文件或刷新前，留意未保存修改的提示。

同一个工作台服务中的标签页共享每门课当前选中的工程。如果另一标签页打开了同一课程的另一个工程，先核对标题下的实际路径。换步骤时发现工程已切换且当前页有草稿，会要求你确认是否放弃草稿。选择取消会留在原工程和原步骤。要回原工程续写，可以先复制草稿，再用「打开项目」重新打开原路径并合并修改。

## 查看输出与恢复连接

一次只运行一个正式检查或个人运行。等待时输出栏会显示状态，操作完成后再显示实际标准输出、错误信息和退出结果。点击「折叠」可以缩起输出，结果摘要仍然可见，任务继续运行。需要更多空间时点「放大」。

等待过程中如果连接中断，先确认启动窗口仍在运行，再点击「继续查询结果」。这个按钮会查询原来那次操作。点「停止等待」只会结束页面的等待。若已关闭服务窗口并重新启动，请使用新窗口给出的地址并按需重新打开工程。遇到课程或文件读取失败时，可用页面上的重试按钮重新加载。

## 指定自己的工作区

把 `EXISTING_DIR` 换成一个已存在、可写入的目录。带空格的路径保留引号。`--port 0` 让系统分配空闲端口。

在源码包根目录运行以下命令。

```sh
cargo run --locked --offline -p labquest -- workbench --workspace "EXISTING_DIR" --port 0 --open
```

Linux 运行包在解压目录执行以下命令。

```sh
./bin/labquest workbench --workspace "EXISTING_DIR" --port 0 --open
```

Windows 运行包在解压目录的终端执行以下命令。

```powershell
.\bin\labquest.exe workbench --workspace "EXISTING_DIR" --port 0 --open
```

## 可以在工作台学哪些课

共 13 门课程、37 个步骤。FirstCard 有 1 步，以下 12 款 Studio 各有 3 步。

UnitLab、QuizDeck、TextScope、LedgerLite、BadgeForge、TermGarden、BatchMeter、MiniKV、NetFetch、ServiceDesk、StoreDesk、AsyncBoard。

进阶 A/B/C、TaskPocket 和 PageMint 独立作品，以及 Rust Book 专题，继续从各自的文档和终端入口学习。需要交互式标准输入或长时间运行的服务时，按该课程原有的终端命令操作。工作台的「运行参数」在启动程序时一次性传入。相关入口见 [课程地图](CURRICULUM.md)、[独立作品路线](INDEPENDENT_PATH.md) 和 [Rust Book 对照学习](BOOK_GUIDE.md)。
