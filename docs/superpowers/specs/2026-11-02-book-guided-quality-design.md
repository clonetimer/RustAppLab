# Rust Book 对照学习与工程验证

## 目标与依据

依据用户“测试 RustAppLab，并从 rust.bootcss.com 学习借鉴完善项目”的要求，保留应用驱动课程，修复实际失败和已复现的检查遗漏，让学员在自己的工程旁查阅相关概念。

基线：`d31f9fca5de8bfa5fb564039f72ed6557c31524e`，0.19.0-dev.2。最近 CI 的 Linux、MSRV 和浏览器任务通过，Windows 在错误实验的 UTF-8 管道解码处失败。进阶 B 的独立工作区未被根 `--workspace` 覆盖，发布指纹未包含它。

## 方案取舍

采用“修复现有流程 + 相关章节映射 + 真实回归”。直接照搬教材会重复现有作品；增加新的领域应用不能解决当前测试遗漏。上述选择由维护者依据本次任务作出。

## 约束

- 保持 Rust 2021、最低 Rust 1.74.0、Windows x64 MSVC / Linux x86_64。
- 中文站使用 Rust 1.37.0 / Edition 2018 的版本说明；现代配置以项目 Cargo.toml 与官方文档为准。
- 阅读导航只读，不执行学员源码、不产生通过记录、不自动联网。
- 保留已有学员工程；新任务卡可增加参考段，不覆盖旧源码。
- B1/B2 独立检查与 B3 累计检查继续使用平台固定合同；B3 验证 list、报告程序和 strict-titles。
- 独立参考工作区的默认/严格 feature、Debug/Release 与 doctest 必须真实执行。
- 新开发结果不继承冻结 RC 的发布资格；B4 与真实异步网络按现有边界继续列为待办。

## 验收

Windows 编码复现回归与实际 CI；全部已有工程测试；进阶 B 缺陷变体应失败；阅读命令前后工程文件不变；源码指纹捕获进阶源码和教材输入变动；最终 Linux、Windows、MSRV、浏览器工作流给出当前提交结果。
