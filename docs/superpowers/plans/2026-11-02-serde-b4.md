# B4 Serde JSON 导出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付真实 Serde JSON 导出课程及累计验收，并保持 B1–B3 的离线兼容。

**Architecture:** 独立 json-export 工作区通过相对 path 依赖 taskcore；平台复制固定清单/合同，准备依赖与评测学员源码分离；按当前源码记录四阶段进度。

**Tech Stack:** Rust 2021，MSRV 1.74.0，serde 1.0.228，serde_json 1.0.145，Python、PowerShell、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-11-02-serde-b4-design.md`

## Global Constraints

- 支持 Windows x64 MSVC / Linux x86_64，Edition 2021 / Rust 1.74.0。
- 原根工作区及 B1–B3 工作区不引入 registry 依赖；B4 独立工作区与 v3 锁文件。
- JSON 导出只读；导航只读；新扩展不覆盖已有目录；准备过程不执行学员源码。
- all=4；显式 3 保持原固定合同；旧 v2 记录不冒充 B4 通过。
- API、字段、依赖版本和报告规则遵循 spec；固定 tests/manifest/lock 不受学员改动影响。

## Review Focus

- 大于 2^53 的 u64、中文/引号/反斜杠/合法控制字符，必须保持值和类型（任务1）。
- 标题 silent trim、重复/零 ID、strict 80/81 字符和只读错误路径（任务1）。
- 空 registry 缓存下旧工程 check3、缺依赖下 check4 的分类与只读导航（任务2）。
- 旧 v2 passed3、新 v3 passed4、JSON-only 变更、后检查3 的导航（任务2）。
- 用户源码/build.rs 不进入依赖准备，已有目录/日志链接不被覆盖（任务2）。
