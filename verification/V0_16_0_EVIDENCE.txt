Rust AppLab 0.16.0 · 实际运行与发布证据（2026-10-29）

一、运行环境与交付范围
- Rust：rustc 1.99.1、Cargo 1.99.1（用户提供的 Linux x86_64 离线工具链）。
- Workspace：17 个 Cargo package；Studio：12 款 × 3 阶段，另有历史 32 关与独立项目。
- 新增 AsyncBoard：真正的 async/await、Future/Poll/Waker、单执行线程 + 一个定时器驱动线程，保存 TSV 报告。
- 无 Tokio/Reqwest/Axum 依赖、无非阻塞网络 reactor/TLS，不能冒充 async HTTP。

二、源码/静态检查
- cargo fmt --all -- --check：通过。
- cargo clippy --locked --offline --workspace --all-targets -- -D warnings：通过。
- cargo clippy --release --locked --offline --workspace --all-targets -- -D warnings：通过。
- cargo build --release --locked --offline --workspace：通过，17 个应用可执行程序。
- python scripts/structural_check.py：通过，含课程链接、32 历史关、12 Studio、演示数据与清单。

四、教学质量与安全边界
- 无答案模板在第1步故意失败；只实现第1步时，第二步尚未实现不应阻挡；正确参考实现完成全部。
- `complete` 遗漏 `delay.await` 会被真实计时测试拒绝；非忙轮询的执行器有独立 `pending_is_not_busy_polled` 测试。
- 任务清单最多128条，等待最大30000ms；非法/重复ID拒绝；报告使用 create_new 防覆盖，拒绝无效目录。
- 工具运行用户自己的 Rust 代码，Studio check 并非恶意代码沙箱；不要上传机密和不可恢复资料进行实验。

五、尚待验证
