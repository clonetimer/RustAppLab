# 0.18.0-dev.5 验证范围

本轮实现 StoreDesk 与 AsyncBoard 的六张微任务卡、十八条提示、第四段事务与等待讲义、真实应用演练及 Future/Waker 小实验。十二款 Studio 合计 36 张卡、108 条提示；学员工程数量仍为 15，没有新增虚构应用。

环境：Linux x86_64，用户提供的 Rust 1.99.1 离线工具链；系统 SQLite。

工作目录实测：Debug 全仓 325 项通过，Release 全仓 315 项通过，各有 15 项教学挑战跳过；文档测试 2 项通过；Python 工具测试 31 项通过。Rustfmt 与两种配置的严格 Clippy、Release 构建均通过。首次 Release 指令因执行时限中断未计入通过；缓存构建后重新完整执行成功。

新两款教学 CLI 实测覆盖：初始失败、逐步补齐、仅完成当前步即可通过、未完成后续步仍失败、全部通过后的交接、修改源码旧报告失效。错误的部分提交和省略 await 实现均被拒绝。维护者测试夹具不等于真人学员作品。

真实参考软件演练：19 次 CLI 调用。Python sqlite3 只读连接独立核对库存与完整流水；正常批次、第二项失败整批回滚、同 SKU 连续调整、重复编号拒绝。提醒报告核对内容和唯一性，等延时不硬编码顺序；覆盖拒绝、重复 ID 不产生报告。

所有 15 个独立学员工程已编译；12 款 Studio 未完成模板的第一步按设计失败。三份页面的桌面/移动 DOM、折叠提示及宽度检查完成；file:// 导航受浏览器管理员策略阻断，未将 set_content DOM 结果当作真实本地导航通过。

最终归档的新目录测试与文件校验由交付包外的 FRESH_VALIDATION.json、原始 EVIDENCE.zip 记录，避免写回源码导致指纹循环变化。
